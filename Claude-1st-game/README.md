# Life Is Short

A tiny, silent pixel-art dodger for the browser. You are the hero, a pixel portrait, and you must keep moving through a stream of office supplies, documents, files, and AI models in solid form.

- Move with the arrow keys or WASD. On touch screens, hold and drag.
- Every death shows a short quote about using your time well.
- Survive 5 minutes and a terrifying cat boss arrives. It shouts `MEOW!` and the letters fly at you. After 20 meows it gives up.

## Play locally

Open `Claude-1st-game/index.html` in any modern browser. There is no build step and no dependencies.

Append `?t=295` to the URL to start close to the boss fight.

## Hosting

If GitHub Pages serves the repository root, the game is at `/Claude-1st-game/`.
